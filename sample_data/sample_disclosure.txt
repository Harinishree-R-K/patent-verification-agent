The invention is a smart water bottle designed to help users track daily hydration. The bottle contains an internal weight-based sensor that measures the volume of liquid consumed each time the user drinks. A small microcontroller inside the base logs each sip event with a timestamp. The bottle connects to a companion mobile application over a wired USB sync cable, which the user must plug in once per day to upload logged data. The mobile application displays a simple daily hydration total and sends the user a reminder notification if no sip has been logged within a three-hour window. The bottle body is made of a double-walled stainless steel to keep beverages cold, and the base unit is removable for battery replacement.
